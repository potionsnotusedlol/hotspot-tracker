# Telegram-бот на Java

Простой рабочий бот на библиотеке [TelegramBots](https://github.com/rubenlagus/TelegramBots) (long polling, Maven, Java 17+).

Команды бота: `/start`, `/help`, `/time`, `/roll`, `/menu` (кнопки). Любой другой текст бот повторяет.

## 1. Получить токен

1. В Telegram откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAH...`. Никому его не показывайте.

## 2. Запуск (самый простой способ)

Дважды щёлкните `run.bat` (или запустите его из терминала). Если токен не задан, скрипт спросит его.
Готовый `target\telegram-bot.jar` собирается один раз (шаг 4), дальше для запуска нужна только Java.

Либо вручную, из папки проекта (PowerShell):

```powershell
$env:BOT_TOKEN = "ВАШ_ТОКЕН"
java -jar target\telegram-bot.jar
```

Остановка — `Ctrl+C`.

Откройте своего бота в Telegram, нажмите **Start** и напишите `/help`.

## 3. Запуск из IDE

1. Откройте папку проекта (File → Open → выберите `pom.xml` → Open as Project). IDE сама подтянет библиотеки.
2. Откройте `Main.java`, нажмите зелёный треугольник рядом с `main` → Modify Run Configuration.
3. В поле **Environment variables** впишите `BOT_TOKEN=ВАШ_ТОКЕН` и запустите.

## 4. Сборка (и пересборка после изменений кода)

Нужны JDK 17+ и [Maven](https://maven.apache.org/download.cgi) (или встроенный Maven вашей IDE, вкладка Maven → Lifecycle → package):

```powershell
mvn package
```

Результат — `target\telegram-bot.jar` (со всеми библиотеками внутри).

## Как это устроено

- `Main.java` — читает токен из переменной `BOT_TOKEN` и запускает приём сообщений.
- `MyBot.java` — обрабатывает сообщения и нажатия на кнопки. Новые команды добавляются в `switch` в методе `onMessage`.

## Частые проблемы

| Симптом | Причина |
|---|---|
| `Не задана переменная окружения BOT_TOKEN` | токен не передан, см. шаг 2 |
| `401` при старте | неверный токен, скопируйте заново из BotFather |
| Бот не отвечает | убедитесь, что программа запущена и открыт чат именно с этим ботом; одновременно запущенная вторая копия бота с тем же токеном даёт конфликт (`409`) |
| `java не является внутренней командой` | Java не в PATH. Укажите путь: `& "C:\путь\к\jdk\bin\java.exe" -jar target\telegram-bot.jar` |
