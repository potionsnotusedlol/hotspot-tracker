# LineAccess для Android

Стартовый экран «Wi-Fi Москвы» показывает число точек из поля `totalElements` гостевого каталога. При открытии и обновлении приложение запрашивает первую страницу из одной записи. Минимальная версия Android — 8.0 (API 26).

## Запуск в Android Studio

1. Откройте каталог `android` через **File → Open**. Для сборки нужны Android SDK Platform 37 и JDK Android Studio. Дождитесь окончания **Gradle Sync**.
2. Запустите Prism по [инструкции проекта](../ops/README.md#api-mock-server). Он читает [общий контракт](../docs/openapi.yaml) и слушает порт 4010. Если Docker недоступен, из корня репозитория можно использовать тот же Prism через `npx --yes @stoplight/prism-cli@5.16.0 mock --host 127.0.0.1 --port 4010 --multiprocess false docs/openapi.yaml`.
3. В **Build Variants** выберите `devDebug`, укажите эмулятор и нажмите **Run**. На Android 17 и выше нажмите **Разрешить доступ** и подтвердите доступ к локальной сети в системном диалоге. Так эмулятор сможет обратиться к Prism по адресу `http://10.0.2.2:4010/`. На примере `guest` контракта v0.1.0 стартовый экран показывает **2**. Кнопка **Обновить** повторяет запрос.

Для физического телефона с USB-отладкой выполните `adb reverse tcp:4010 tcp:4010`, задайте `lineaccess.devUrl=http://127.0.0.1:4010` в локальных пользовательских настройках Gradle и пересоберите `devDebug`. Вернуться к стандартному адресу эмулятора можно удалением этого свойства.

## Вариант prod

Задайте адрес рабочего API в пользовательском `gradle.properties` как `lineaccess.prodUrl` или через переменную окружения `LINEACCESS_PROD_URL`, затем соберите вариант `prod`. Значение — HTTPS-адрес без пути, параметров и учётных данных. Если адрес ещё не назначен, приложение показывает сообщение о конфигурации. У `dev` и `prod` разные идентификаторы приложений, их можно установить одновременно.

## Контракт и проверка

Модуль `api` генерирует модели Kotlin и интерфейс Retrofit из `docs/openapi.yaml` при компиляции. Сгенерированные файлы находятся в `api/build/generated/openapi`. Hilt передаёт репозиторий в `CatalogViewModel`, а Compose получает состояние через `StateFlow` с учётом жизненного цикла. Ошибки отображаются по-русски. После ответа 429 приложение учитывает `Retry-After` перед повторным запросом.

В Windows выполните команды из каталога `android`.

```powershell
.\gradlew.bat :app:assembleDevDebug :app:assembleProdDebug
.\gradlew.bat :app:testDevDebugUnitTest :app:testProdDebugUnitTest
.\gradlew.bat :app:connectedDevDebugAndroidTest
```

Последняя команда выполняет тесты интерфейса на подключённом эмуляторе или тестовом устройстве. Для проверки восстановления остановите мок, нажмите **Обновить**, затем снова запустите мок и нажмите **Повторить**.
